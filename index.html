CSIT843A · Lecture 4 · Unsupervised learning

Finding structure with no answer key.

So far, every model we trained was given the inputs and the answers. Unsupervised learning takes the answers away. The computer only sees the data and has to discover the structure on its own: groups of similar rows, or a few summary columns that keep most of the information.

01Take the answers away

In supervised learning every row had an answer column, \(y\): a price, spam / not spam, a species. In unsupervised learning we only have the \(X\) columns. Nobody tells us the right answer, so the goal changes: we are not predicting, we are exploring. Are there groups? Is there a simpler way to describe the data? Can we draw it in 2D so a human can look at it?

What the computer sees

Switch views. The points never move; only what we know about them changes.

Analogy

Supervised learning is a teacher marking your homework. Unsupervised learning is being handed a box of 500 photos and asked to "sort these into piles that make sense". There is no single correct answer, and you decide what "makes sense".

03Two jobs: rows or columns?

Unsupervised methods come in two families. Clustering groups the rows (customers, patients, documents) so that rows in the same group are similar. Dimensionality reduction shrinks the columns: if we have 50 features, can 2 or 3 new features describe the data well enough to plot it?

One table, two jobs

Ten students, five measurements, no grade column.

Easy way to remember

Clustering shortens the list of types of rows. Dimensionality reduction shortens the list of columns.

05Classification vs clustering

Both put things into groups, which is why students mix them up. The difference is who defines the groups.

Classification (supervised)Clustering (unsupervised)
Training dataFeatures and a label for every rowFeatures only
Number of groupsKnown in advance (the classes)Unknown: you choose it or the method suggests it
Meaning of a groupGiven ("spam", "setosa")Discovered; a human interprets it afterwards
GoalPredict the class of a new pointDescribe the structure of the data you have
How we judge itAccuracy on a test setNo answer key: is it sensible and useful?
ExamplesKNN, logistic regression, SVM, treesK-means, hierarchical, DBSCAN, GMM

06Where it is used

medicine

Cancer subtypes

Tissue samples from many breast-cancer patients. Nobody knows how many subtypes exist. Clustering suggests groups of tumours that look alike, to be studied as possible subtypes.

biology

Gene expression

Thousands of genes per sample, far too many to look at. Dimensionality reduction squeezes them into a few summary features we can plot.

text

News grouping

News aggregators group thousands of articles about the same story without anyone tagging them first.

images

Face compression

A face photo has thousands of pixels. Before training a classifier we often compress each face into a short list of numbers, without labels.

business

Customer segments

Group customers by spending and behaviour, then design an offer for each segment.

security

Anomaly detection

Points that fit no cluster (unusual logins, odd transactions) are worth a closer look.

07Why it is harder

1

The goal is fuzzy

"Find interesting patterns" is not a precise target. Two analysts can find two different, equally reasonable groupings.

2

No answer key

In regression we measured test error. Here there is nothing to compare with, so we cannot simply compute accuracy.

3

Many dimensions

Data often has many columns, which makes plots impossible and distances less meaningful.

So in practice we judge unsupervised results by asking: are the groups sensible to a domain expert, and are they useful for a decision?

The curse of dimensionality, seen

Point 3 is easy to say and surprising to see. Scatter 200 random points in a cube with \(d\) dimensions and measure the distance between every pair. As \(d\) grows, all distances crowd towards the same value: the nearest neighbour is barely nearer than the farthest one. Methods that rely on "close" vs "far" (like K-means) suffer.

Distances in high dimensions

Histogram of all pairwise distances, divided by the largest one.

The contrast \((d_{\max}-d_{\min})/d_{\min}\) measures how different "near" and "far" are. In 2D it is huge; in 1000D it is small. This is why we often reduce dimensions with PCA before clustering.

08Families of clustering methods

centroid-based · this lecture

K-means

Each cluster has a centre point. Points join the nearest centre.

 hierarchical · this lecture

Agglomerative

Build a tree showing which points join together first.

 model-based · beyond

Gaussian mixtures

Each cluster is a bell-shaped distribution; the data is a mix of them.

 density-based · beyond

DBSCAN

Clusters are dense regions separated by sparse ones. Finds odd shapes and noise.

Hard vs soft clustering

In hard clustering each customer is in exactly one group. In soft clustering a customer can belong partly to several, for example 70% "student" and 30% "family". K-means and hierarchical clustering are both hard.
